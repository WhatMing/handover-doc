# handover-doc

> 一个通用 Agent Skill：分析任意前端 / 后端 / 全栈项目的 **Git 历史与本地文件**，一键生成带交互式思维导图的**交接文档**（单一 HTML 文件，可直接分享、打印、导出 PDF）。

面向"人走活还在"的场景：离职交接、项目移交、接手人快速上手。

---

## 它能做什么

- **只用 Git 仓库与本地文件**，不访问任何外部服务，内网可用
- **每条结论可追溯** —— 工作项标注提交哈希、记录文档章节或代码路径，不写无依据的结论
- **接手人不问人也能上手** —— 前置依赖、安装启动命令、环境变量键名、常见踩坑一应俱全
- **单一 HTML 产物** —— 内置交互式思维导图、目录滚动高亮、代码一键复制、A4 打印 / 导出 PDF 样式
- **自动按项目形态裁剪** —— 自动识别前端 / 后端 / 全栈，相关人员表只填"对接方"角色

## 产出的文档长什么样

标准章节按**接手优先级**排序（先让人跑起来、避开坑，再看历史与明细）：

1. 项目概述（定位、背景、当前状态、仓库信息 + 相关人员表 + 五步上手速览）
2. 思维导图总览（可缩放、拖拽、折叠分支）
3. 快速上手 / 环境搭建（前置依赖 → 安装 → 启动 → 验证 → 常见问题）
4. 工程结构与模块职责
5. 功能模块详解
6. 潜在风险与注意事项（按高 / 中 / 低分级）
7. 构建与部署
8. 接口清单
9. 技术栈清单（精确版本）
10. 已完成工作（工作总量 + 主干工作一览，不罗列琐碎提交）
11. 数据模型（纯前端项目自动省略）
12. 交接确认清单 + 附录

## 安装

### 方式一：装到项目级（只对当前项目生效）

```bash
git clone https://github.com/WhatMing/handover-doc.git .trae/skills/handover-doc
```

### 方式二：装到用户级（对所有项目生效）

```powershell
# Windows
git clone https://github.com/WhatMing/handover-doc.git "$env:USERPROFILE\.trae-cn\skills\handover-doc"
```

```bash
# macOS / Linux
git clone https://github.com/WhatMing/handover-doc.git ~/.trae-cn/skills/handover-doc
```

> 也可以直接把本仓库的 `SKILL.md` 与 `template.html` 复制到目标 skills 目录下的 `handover-doc/` 文件夹中。

## 使用

在支持 Skill 的 Agent（如 Trae）对话中直接说：

- `给 D:\path\to\project 生成交接文档`
- `我要离职交接，把这个项目整理成交接文档`
- `handover`、`项目交接`、`移交`

技能会自动执行六步工作流：识别项目形态 → 收集 Git 与本地文件信息 → 归纳"做了什么" → 构建思维导图 → 生成 HTML 文档 → 验证交付。

**注意**：产品/业务负责人、发布人员等信息无法从代码推断，Agent 会向你确认，请如实提供。

## 工作流程（六步）

| 步骤 | 内容 |
|---|---|
| 1. 识别项目形态 | 读根目录特征文件（package.json / pom.xml / go.mod…）判定前端 / 后端 / 全栈 |
| 2. 信息收集 | Git 提交明细、贡献者统计、分支远程、变更热度 Top20；README、记录文档、依赖版本、目录树、配置、路由、接口、数据模型 |
| 3. 归纳"做了什么" | 按功能 / 修复 / 重构 / 文档归组，每条标注依据，汇总工作量 |
| 4. 构建思维导图 | 将大纲写入 `template.html` 的 `MIND_DATA` 树形对象 |
| 5. 生成 HTML | 基于模板产出十二章节文档 |
| 6. 验证与交付 | 敏感值零泄漏、版本为实测值、导图渲染与兜底两场景验证 |

## 运行要求

- **需能访问 `cdn.bootcdn.net`**：思维导图库 [simple-mind-map](https://github.com/wanglin2/mind-map) 0.14.0 经 BootCDN 加载
  - 库文件约 6.5MB，**首次打开需等待下载**完成后才显示导图
  - 已做异步加载与兜底：库未就绪时正文照常阅读，导图区显示提示文案，**不会出现"章节内容缺失"**
- **`git` 命令行工具**（用于读取提交历史）
- 生成环境：Trae 或任何支持 Skill 的 Agent；文档查看只需浏览器

## 目录结构

```
handover-doc/
├─ SKILL.md         # 技能定义：定位、六步工作流、相关人员必填规则、安全红线、质量要求
├─ template.html    # 交接文档 HTML 模板：样式 + 思维导图 + 初始化与兜底逻辑
├─ README.md
└─ LICENSE
```

## 设计要点（都踩过坑）

- **导图库必须 `defer` 异步加载并置于文档末尾**：该库 min 版约 6.5MB，若以同步 `<script src>` 放在文档中段，浏览器解析到该标签即中断 HTML 解析，后续章节长时间不进 DOM（实测内网约 53 秒），用户表现为"内容缺失"。现方案为末尾 `defer` + 轮询就绪 + 加载占位 + 失败兜底。
- **构造函数是 `window.simpleMindMap.default`**：UMD 全局对象只暴露 `default` 键。
- **只用已验证的视图 API**：`view.enlarge()` / `narrow()` / `fit()` / `reset()`；0.14.0 不存在 `expandAll` / `collapseAll`，节点展开折叠改用组件自带的圆点交互。
- **风险定性以用户口径为准**：项目正常运行、无遗留问题时，章节定名为"潜在风险与注意事项"，禁止把非阻塞事项夸大为高危吓退接手人。
- **敏感值零泄漏**：`.env.*` 只读键名、不读值；密钥 / Token / 密码 / 连接串零出现。
